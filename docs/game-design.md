# つたのぼり — 企画と作り方の記録

サルがロープを木の枝にかけて振り子のように揺れ、水が来る前にジャングルのてっぺんまで登るゲーム。iPad (横・縦どちらも) 向け。

作り方は `2nd-brain-project/docs/game-making-playbook.md` (550 Atelier の動画から作った 8 つの手順) に従った。各手順で何をしたかを下に残す。

## 1. 書いてない 9 割を読む (決めたこと)

- 遊ぶ人: 子ども (iPad、横画面が主、縦でも遊べる)。説明を読まなくても遊べること
- 操作: 画面のどこでも押すとロープが押した方向へ飛ぶ (近くの枝に吸い付く手助けあり)。押している間はぶら下がって漕ぐ。指を離すと飛ぶ
- 勝ち: 一番上の「ゴール」の枝につかまる。負け: 水に 3 回落ちる (ハート 3 つ)
- 最初の 30 秒: 1-1 だけ手引きの吹き出しを 3 段階で出す (おしたまま → はなすと とぶ → えだを タッチ)
- 星 3 つ: てっぺん / くだもの全部 / 空振りなし
- 積み上げ: 子ザル (各面に 1 匹) を助けると「サルの村」が育つ。くだものでぼうし・ロープの色を買える。性能は変えない (腕前の遊びを壊さないため)

## 2. まずは四角で遊ぶ

絵の前に、物理と面とルールだけ (`src/game.js`) を作り、自動プレイ (`src/autoplay.js` / `tools/bot.mjs`) で遊べるかを確かめた。描画と音は持たないので node だけで何百回も回せる。

## 3〜6. 絵・タメ・手ごたえ・音

- 色の役割: サル = 暖色で一番明るい (ふち光つき) / つかめる物 = 黄色の光る輪 (届く時は濃く) / 危険 = ピンク・赤 (枝のひび、水が近い時の画面の縁) / 背景 = 暗く彩度低め
- 影は黒を混ぜず、葉は青緑、幹とサルの毛は紫寄りへ色相をずらして暗くした
- 形で見分ける: サル (丸い耳とハートの顔)、鳥 (くちばしと翼)、枝 (葉のかたまり)、つる (垂れた線)、細い枝 (葉の小さい細い棒)
- 予告: 細い枝は「ミシッ → ピキピキ → ポキッ」とひびが増え、震えてから折れる。鳥は疲れると汗と羽ばたきで知らせてから落とす。水は画面の外にいる時から下の青い帯で近さを見せ、近いと画面の縁が赤く点滅して警告音
- 手ごたえ: つかんだ瞬間の止め (ヒットストップ)、画面ゆれ、葉・星・紙ふぶきの粒、離した時の光の輪、のび・つぶれ
- 音: すべての動きに効果音。毎回少し高さを変える。れんぞくが増えると音が上がる。水が近いと音楽に低い音が加わる。すべてその場で合成 (`src/audio.js`)

## 7. 何百回もテスト (自動プレイ)

`node tools/bot.mjs 263 0.10` で各面 263 回。ぶれ (秒) を大きくすると子どもに近い腕前になる。

自動プレイで見つけて直した「みんなが詰まる場所」:

| 見つけたこと | 直し方 |
| --- | --- |
| ゴールが最後の枝の 230 上で、ほぼ全員が最後に落ちる | ゴールの枝につかまればクリアに |
| 壁際の枝で揺れるたび幹に当たり、勢いが消えて登れない | ぶら下がり中に幹に当たったら「キック」で勢いがつく (0.7 秒に 1 回まで) |
| 長いつるで端から端まで揺れて両側の幹に当たり続ける | つるの長さを短くした |
| 最初のジャンプの失敗が一番多い落ち方 | スタートに地面。水が来る前なら落ちてもやり直せる |
| 地面の端に降りると、どの枝にも届かず立ち往生 | 着地したら真ん中へ歩いて戻る |
| 3 面が 4 面より難しい | 細い枝を減らし、折れるまでを 1.5 秒に |

子ども相当 (ぶれ 0.14 秒) のクリア率: 1-1 99% / 1-2 96% / 1-3 90% / 1-4 96% / 1-5 86% (2026-10-15)。くだものは一つずつなら全部取れることを確認済み (`tools/fruit-stats.mjs`)。全部を 1 回で取るのは難しい (★2 は何回か挑戦する目標)。

当たり判定は見た目よりやさしい: 水は体の中心が水面より下に入るまで落ちない、くだもの・子ザルは見た目より広く取れる。

## 8. 面白さは人が決める

ここから先は子どもに遊んでもらって決める。見たいこと: 説明なしで遊べるか / 「もう 1 回」と言うか / どこで投げ出すか。
